# Wasp

Bold yellow and black: angular tabs, decisive borders, geometric stripes, and unmistakable selection in Light and Dark.

## Installation

Install this repository through Valley's Themes settings, or download the ZIP from GitHub Releases and install the theme package. Select the theme in Appearance and choose Light or Dark. Themes are free.

## Package

`manifest.json` defines the theme identity. `theme.css` provides its appearance. `SHOWCASE.md` contains the Community previews.
